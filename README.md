# TINS Workshop CFP Website

Static HTML version of the TINS Workshop Call for Papers for IEEE GLOBECOM 2026.

## Publish on GitHub Pages

Upload these files to a GitHub repository:

- `index.html`
- `fig/`

Then enable GitHub Pages from the repository settings and choose the branch/root that contains `index.html`.

The original LaTeX source is kept as `main.tex` for reference, but it is not required for the website.

Note: EPS files are source assets and are not reliably supported by browsers or GitHub Pages. The webpage uses browser-safe official PNG assets downloaded from the IEEE Communications Society resources page:

- `fig/official-ieee-globecom.png`
- `fig/official-comsoc-ieee-black.png`

The footer theme icons are generated directly in `index.html` as inline SVG, matching the LaTeX source's generated icon approach instead of using image files.
